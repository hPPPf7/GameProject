# 菜鳥調查隊日誌

《菜鳥調查隊日誌》是一款以 Python 與 Pygame 製作的劇情調查遊戲。玩家扮演第一次被派上外勤的新人調查員，接下淺川村整村失聯的任務，帶著錄製器與簡報資料前往現場，逐步揭開異常現象、研究據點與「樣本#07」之間的真相。

遊戲以文字事件、選項決策、簡易戰鬥、背包道具與命運值變化推進。玩家的選擇會影響角色狀態、事件分支、紀錄內容與後續章節走向。

## 遊戲介紹

前哨站東北方的淺川村突然失聯，偵查用的傀儡也只回傳錯碼。你被隊長派往現場，原本看似普通的調查任務，很快變成一連串無法用常識解釋的異常事件。

在荒野、村莊、研究據點與終端觀測室之間，玩家會遇見發熱的石頭、結晶化的村民、詭異的投影、失控的實驗體，以及不斷指向自身身分的線索。任務的核心不只是「村民為什麼失聯」，還包括「你究竟是誰」。

## 核心玩法

- 閱讀事件文本，根據當下狀況選擇行動。
- 透過選項改變命運值、旗標、背包道具與章節進度。
- 在戰鬥事件中選擇攻擊、撤退或其他特殊行動。
- 透過任務紀錄與事件回報追蹤調查過程。
- 隨章節推進，逐步進入淺川村、研究據點與核心機組。

## 遊戲特色

- **劇情分支**：事件資料以 `data/story_data.json` 管理，選項可觸發不同結果、文字變體與章節跳轉。
- **命運系統**：玩家行動會改變命運傾向，影響事件敘事語氣與後續發展。
- **調查紀錄**：遊戲會保留文字紀錄，呈現玩家的選擇、回報與任務過程。
- **戰鬥事件**：部分事件會進入戰鬥流程，讓調查過程帶有風險與資源壓力。
- **桌面與 Android 打包**：專案提供 PyInstaller 與 Buildozer 設定，可輸出 Windows 執行檔或 Android 測試版。

## 技術概覽

遊戲會載入 `data/story_data.json` 的劇情資料，搭配 `assets/` 內的圖片、字型與音效資源，透過事件系統、戰鬥系統、命運系統與玩家狀態管理推進流程。

## 角色動畫與保留的 3D 試作

目前遊戲固定使用 **2D 原版**，使用原本的待機、`player_walk.png` 走路與 `player_attack.png` 揮劍圖片。
3D 試作因效果未達預期而停用；上方切換按鈕、設定中的角色版本選項與 F3 切換均已移除。
即使舊設定記錄了 `character_style: "3d"`，重新啟動後仍會使用 2D，不影響既有存檔。

3D 模型、骨架、走路與揮劍動畫，以及程式中的動畫載入能力仍保留，供日後繼續調整。
遊戲不會載入這組 3D 圖片，也不需要執行 Blender。

保留的 3D 圖片在 `assets/characters/rookie_3d/`：

| 動作 | 排列 | 格數 | 播放速度 |
| --- | --- | --- | --- |
| `idle.png` | 4 欄 × 2 排 | 8 | 6 FPS |
| `walk.png` | 4 欄 × 2 排 | 8 | 10 FPS |
| `attack.png` | 5 欄 × 3 排 | 15 | 15 FPS |

每格都是 128 × 96，統一相機、角色比例與原點。
對應的 `.animation.json` 仍可用既有檢查視窗預覽與調整，但不會套用至目前的遊戲。

```powershell
.\inspect_sprites.ps1 assets\characters\rookie_3d\walk.png
.\inspect_sprites.ps1 assets\characters\rookie_3d\attack.png
```

Blender 原始模型與輸出腳本保留在 `art/blender/rookie_pixel/`，詳見該資料夾的 `README.md`。

## 開發環境

建議使用 Python 3.10 以上版本。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install pygame
```

```powershell
python -m pip install pyinstaller
```

## 執行遊戲

在專案根目錄執行：

```powershell
python main.py
```

遊戲會自動從專案內的 `assets/` 與 `data/` 讀取資源。開發模式下，存檔、設定與錯誤紀錄會寫入使用者資料目錄：

```text
%LOCALAPPDATA%\GameProject
```

若沒有 `LOCALAPPDATA`，則會改用使用者家目錄下的 `GameProject`。

### 玩家走路動畫

走路圖使用 `assets/sprite_sheet/player_walk.png`，目前原稿為 1536 × 1024，排列為 3 欄 × 2 排，每格 512 × 512。目前設定為 18 FPS，每格約 0.056 秒，一個循環約 0.33 秒。圖片旁的 `player_walk.animation.json` 可設定分格、FPS、播放順序與每格偏移；缺少設定檔時使用六格、10 FPS 的預設值。前進探索、攻擊時靠近敵人與返回原位都共用這組動畫。

目前使用的走路圖採朝右側面視角；配套設定已校正各格的頭部水平中心與落地腳高度，減少原稿在不同欄位的位置差造成的跳動。

移動時間依實際距離與步頻計算，探索、接近與返回共用相同移速，避免短距離和長距離都硬塞在固定秒數內。攻擊後保持朝右，倒序播放走路格退回原位；目前六格、18 FPS 的設定對應每秒 360 遊戲像素，是先前的 1.8 倍。橫越 320 遊戲像素約需 0.89 秒（原本 1.6 秒），步伐和位移一起加快；場景淡入淡出時間另外計算。

替換圖片時，請維持相同的六格排列、PNG 透明背景，以及各格一致的角色比例與腳底高度。程式會保留各格留白並等比例縮放至 96 像素高，不必手動拆成六個檔案。舊版 `assets/images/player/walk/` 圖片保留作為參考，目前不再載入。

### 玩家攻擊動畫

遊戲使用 `assets/sprite_sheet/player_attack.png`，共有九個朝右揮劍姿勢。
目前設定為 **12 FPS**，揮劍本身約 **0.75 秒**，接近敵人與返回原位的時間另計。
播放順序為 `1, 2, 3, 5, 4, 6, 7, 8, 9`：原圖第 5 格是向前出劍，第 4 格已向下收劍，
因此調整這兩格的先後，使揮擊軌跡連續。攻擊音效與結果在第 5 張來源圖出現時觸發一次，角色返回原位後才推進事件或開始敵方行動。

原始 PNG 為 1254 × 1254，雖呈 3 欄 × 3 排排列，但部分腳底與劍跨過等分格線。
`player_attack.animation.json` 的 `frame_rects` 記錄九個獨立取圖範圍，
`canvas_size` 統一為 512 × 400，並以逐格偏移校正站位與腳底。
遊戲與檢查視窗共用這些設定，縮放至 96 像素高；原始 PNG 保持不變。
攻擊距離依劍尖與敵人的可見輪廓計算，避免透明留白讓揮劍離敵人太遠。

```powershell
.\inspect_sprites.ps1 assets\sprite_sheet\player_attack.png
```

可以調整速度、順序與偏移，儲存後重新啟動遊戲即可套用。
這張圖已設定獨立取圖範圍，可用「拖拉調整各格取圖範圍」校正。「套用分格」會先確認，再清除獨立取圖範圍、播放順序與偏移，恢復等分取圖。
日後更換原圖時，需要重新檢查這些範圍。舊的 `assets/images/player/attack/` 素材保留作參考，遊戲不再載入。

### 戰鬥回饋與存檔

- 攻擊時加入短暫停頓、結果提示；受擊時閃白與後退，擊倒的敵人會淡出。效果由程式繪製，沿用現有素材。
- 動作期間選項顯示「攻擊中」、「返回中」或「敵方行動」，並停用重複選擇。
- 開啟設定或回到主選單時暫停角色與事件動畫，背景音樂仍正常播放。
- 戰鬥動畫途中儲存時，保留該次行動開始前的完整狀態；雙方行動結束後再存入完成的回合。中途離開後繼續遊戲，會回到該次行動前，避免只記下一半結果。
- 修正敵人資料存成文字後造成的讀檔戰鬥錯誤，同時相容既有存檔中的敵人名稱、字典與舊文字格式。

### 介面質感與動態

- 音樂與音效的最高輸出由 0.35 提高為 0.70，相同音量設定下的輸出增益為原來兩倍；設定中的音量百分比與靜音維持原有作用。
- 場景、按鈕、狀態區、背包與設定視窗移除裝飾細框，以深藍灰底色、固定微粒質感與琥珀色提示區分區域，日誌保持乾淨底色。
- 按鈕以霧面像素顆粒、整面上亮下暗的光影與底部實心陰影呈現厚度，不繪製細線邊框。滑鼠移入時底色逐漸變亮；滑鼠或觸控按下時，表面下沉 1 遊戲像素並略微變暗，點擊範圍維持不變。停用中的按鈕降低質感對比，不產生滑過回饋。
- 可操作按鈕加入短促點選音效，跟隨設定中的「音效音量」，靜音時也會靜音。點擊空白、停用選項與捲動文字不會觸發按鈕音效。聲音使用專案內合成的 `assets/sounds/sfx/button_click.wav`。
- 設定提供「音樂音量」、「音效音量」與獨立的「打字音量」，均可按 `−／＋` 調整 0～100%，每次 10%；打字音量設為 0% 可單獨靜音，設定會自動保存。舊設定第一次使用時，打字音量沿用原本音效音量（包含靜音），後續可分開調整。
- 調整打字音量後試聽三下打字聲；連續調整會替換上一段試聽。靜音、關閉設定或切出視窗會取消試聽。
- 逐字播放時加入打字提示音，使用 `assets/sounds/sfx/typewriter_tick.wav`，由「打字音量」獨立控制，使用與其他音效相同的輸出曲線，不再額外壓低音量。只在新字元出現時觸發，略過空白與標點，兩次提示至少間隔 80 毫秒；慢畫面或直接跳過文字不會補播一串聲音。開啟設定暫停劇情、關閉逐字播放或打字音量設為 0% 時，也不會持續發出打字聲。
- 開頭與結尾的劇情模式不繪製場景細框與文字面板邊框，文字直接呈現在乾淨底色上；一般遊戲介面仍保留面板質感。
- 文字超出顯示範圍時，右側顯示滾動條與上下箭頭。可用滾輪、拖曳滑塊、點擊箭頭或軌道捲動；手機也可拖曳滑塊或上下滑動文字。滑動開頭／結尾的文字時不會跳到下一段，手機上輕點文字後放開才推進劇情。滾動條和文字使用相同的換行寬度及可見行數，短內容會自動隱藏滾動條。
- 往上閱讀時固定當前位置，新文字與打字完成不會把畫面拉回底部；點擊文字區底部的「回到最新」才恢復跟隨。提示列固定保留空間，避免遮住文字或造成跳動。
- 開頭與結尾的文字播完後顯示輕微明暗變化的「點擊繼續」或「點擊返回選單」。手機開頭最後一段也等待點擊，不再自動略過。
- 讀檔沿用目前的逐字播放設定，不以舊存檔覆蓋偏好；開頭與結尾也尊重此設定。
- 切換視窗、最小化或應用程式進入背景時暫停文字、動畫和全部音訊，並顯示暫停提示。返回時沿用原本的彈窗狀態，避免補播離開期間的動畫或聲音。
- 存在存檔時，開始新冒險會先詢問是否取代。取消保留原存檔，確認後才清除；仍使用單一存檔，不建立額外備份。
- 點擊背包物品顯示名稱、來源與用途說明，可切換查看其他物品。查看不消耗物品、不增加日誌，關閉後繼續遊戲；報告的已知線索依照目前劇情顯示。
- 出劍接觸、受擊與擊倒時，上方場景有短暫震動；日誌、狀態與按鈕保持穩定。設定中的「畫面震動」依序切換「關閉／輕微／標準」，預設輕微，會記住下次啟動的選擇。關閉震動仍保留原本的打擊停頓與受擊提示。
- 耐久下降時數字短暫變紅並浮出減少量，底部小格顯示剩餘耐久。新取得道具時，對應背包格亮起、圖示小幅彈動；超過六格時提示末格的彙總位置。讀檔及重新排序道具不會觸發取得提示。
- 主選單營火加入局部暖光變化與少量像素火星，沿用原始背景，不改動圖片；開啟設定時暫停環境動畫。
- 設定視窗淡入淡出並壓暗後方畫面，關閉動畫期間會阻擋穿透點擊。遊戲中的角色與提示動畫會等待視窗完全關閉後繼續。

上述效果由 `ui_theme.py`、`ui_effects.py` 與 `combat_feedback.py` 繪製，不需要額外美術圖片。

### Sprite Sheet 檢查視窗

在 Windows 專案根目錄執行：

```powershell
.\inspect_sprites.ps1
```

也可以執行 `python sprite_sheet_inspector.py`，或在後面加上其他圖片的路徑。工具使用專案既有的 Pygame 與 Python 標準庫 Tkinter，不會啟動遊戲或讀寫遊戲存檔。

- 預設開啟目前的玩家走路圖；可播放／暫停、逐格查看、調整 FPS 與縮放。
- 提供透明棋盤格、前格半透明疊影、中心線、腳底線，以及橫向移動預覽。
- 勾選「連續動作」可循環查看待機、接近、攻擊與返回，使用遊戲的移動速度與後退播放。開啟 `player_walk.png` 或 `player_attack.png` 時，該圖片未儲存的速度、順序與位置校正會即時套入整段預覽；其餘動作使用現有遊戲設定。
- 勾選「並排比較」可同步比較平滑與清晰縮放，單張動作和連續預覽皆可使用。比較只作用於工具；目前遊戲維持平滑縮放。
- 「切圖與校正」可調整欄數、排數、播放順序，以及各格的 X/Y 偏移。格號從 1 起算，按上排左到右、再下一排編號；可重複格號增加停留時間。
- 「拖拉調整各格取圖範圍」可在原圖上移動選取框、拖曳左上／右下角縮放，或從框外拖出新範圍。按「套用到預覽」後檢查結果，再按「儲存動畫設定」；移動取圖起點時會同步補償偏移，維持角色在共同畫布的位置。
- 按「儲存動畫設定」才會寫入圖片旁的 `.animation.json`，不會修改原圖。調整玩家走路圖後，重新啟動遊戲即可套用速度、順序與偏移；預覽縮放、背景與橫向移動速度只作用在檢查視窗。
- 快捷鍵：空白鍵播放／暫停、左右鍵逐格、`Ctrl+O` 開啟圖片、`Ctrl+S` 儲存。

新的角色動畫請先建立朝右的側面基準圖，再生成走路循環。完整可複製提示詞與驗收步驟見 [角色動畫製作指引](docs/character_animation_prompts.md)。

## 常見問題

### 啟動時找不到圖片、字型或音效

請確認是從專案根目錄執行 `python main.py`，且 `assets/` 目錄存在。

### PyInstaller 打包後找不到資料檔

請使用 `build_game.py` 或 `build.ps1`，它們會將 `assets/` 與 `data/` 一起加入打包命令。

### 遊戲發生未處理錯誤

遊戲會將未處理例外寫入 `crash.log`。開發模式下可到 `%LOCALAPPDATA%\GameProject\crash.log` 查看。
