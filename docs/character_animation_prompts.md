# 角色動畫製作與 ChatGPT 提示詞

本專案的玩家在畫面左側，探索與接近敵人時往右移動。角色應採固定朝右的側面視角。早期已淘汰的走路圖偏正面，六格的腿部動作也不夠明確；調慢速度能幫助檢查，但不能補出缺少的腳步。目前的 `player_walk.png` 使用朝右側面的版本。

製作順序：角色原圖 → 確認朝右側面基準圖 → 以基準圖生成單一動作的 sprite sheet → 用專案檢查視窗驗證 → 儲存動畫設定。

## 第一步：先建立朝右的全身側面圖

在 ChatGPT 對話上傳角色原圖，貼上：

```text
請根據我上傳的圖片，製作這名角色的「朝右全身側面基準圖」，
後續會用它製作 2D 橫向遊戲的走路動畫。
這一步只生成一名角色、一個站姿。

視角：
- 角色固定朝畫面右方，接近 90 度的標準側面。
- 臉、胸口、骨盆與雙腳都朝右；鏡頭只看見同一側身體。
- 臉主要呈現側臉與一隻可見的眼睛，不看鏡頭，不採正面或正面三分之二視角。
- 雙腿略微前後錯開，讓近鏡側腿與遠鏡側腿能分辨。
- 相機水平固定，完整呈現頭頂到腳底以及所有裝備。

保留角色設計：
- 保留原圖的灰色頭髮、臉部特徵、頭身比例、卡其棕色外套、
  藍色圍巾、背包、鞋子與手持裝備。
- 保留原本手持物的用途、外形與持用的手，不擅自改成武器。
- 看不到的裝備部分可被身體自然遮擋，不為了全部露出而扭轉身體。
- 保留原圖的像素美術風格與配色，輪廓清楚。

輸出：
- 一張 1024 × 1024 PNG，真正透明背景。
- 角色完整站在畫布中央，四周保留足夠空白。
- 不畫背景、地面、投影、文字、箭頭、格線或假透明棋盤格。
```

先確認方向再繼續。如果仍偏正面，在同一對話修正：

```text
請只修正角色視角：讓角色的臉、胸口、骨盆與雙腳全部轉為朝右的標準側面。
目前仍能看到太多正面的胸口或雙眼。請保留同一角色的服裝、比例、配色與裝備，
改成側面輪廓；不要用水平翻轉代替視角修正。
```

若原始參考只有正面，背包側面等細節需要生成模型推定；確認滿意後，後續動作一律沿用這張側面基準圖。跨到新對話時，要重新附上基準圖。

## 第二步：用側面基準圖生成六格走路循環

附上已確認的側面基準圖，或在同一對話明確指定它，貼上：

```text
請以剛才確認的「朝右全身側面基準圖」為唯一角色與視角參考，
製作 2D 橫向遊戲用的六格原地走路循環 sprite sheet。

輸出：
- 一張 1536 × 1024 PNG，真正透明背景。
- 3 欄 × 2 排，共六格；每格 512 × 512，格子沒有額外間隔或邊框。
- 順序為上排左到右的第 1、2、3 格，再下排左到右的第 4、5、6 格。
- 每格一名完整角色；頭髮、雙腳、背包與手持物全部留在各自格子內。
- 不畫文字、編號、背景、地面、投影、格線或假透明棋盤格。

固定視角與外觀：
- 六格都維持基準圖的朝右標準側面；頭、胸口、骨盆與雙腳不轉向鏡頭。
- 保持相同臉型、髮型、頭身比例、服裝、配色、背包與裝備。
- 裝備始終在同一隻手；近鏡側腿與遠鏡側腿不能交換身份。
- 相機、角色大小與身體根部的水平位置固定，不逐格向右平移角色。
- 角色在遊戲裡的水平移動由程式處理。

六格必須呈現一整個左右腳交替的步行循環：
1. 近鏡側腳向右前伸接地，遠鏡側腳留在身後。
2. 近鏡側腳支撐身體，遠鏡側腳離地，屈膝向前經過支撐腿。
3. 遠鏡側腳向右前伸準備落地，近鏡側腳移到身後準備蹬地。
4. 遠鏡側腳向右前伸接地，近鏡側腳留在身後，與第 1 格的雙腿位置互換。
5. 遠鏡側腳支撐身體，近鏡側腳離地，屈膝向前經過支撐腿。
6. 近鏡側腳向右前伸準備落地，遠鏡側腳移到身後準備蹬地，能自然接回第 1 格。

動作要求：
- 雙腿確實交替前後跨步、經過身體中心，膝蓋和腳踝有清楚的過渡姿勢。
- 手臂隨步伐自然擺動，持物的手可減小擺幅。
- 接地腳都使用相同的地面高度；抬起的腳可以高於地面。
- 身體保留自然的小幅上下起伏，圍巾與背包只作輕微跟隨。
- 第 6 格接第 1 格時方向與姿勢連續，不額外重複首格作為結尾停格。
- 不要只改變手臂、只讓身體浮動，或把六個相近站姿當作走路動畫。
- 不添加速度線、殘影或動態模糊。
```

這些像素尺寸是交付規格，生成後仍需檢查實際檔案。若模型沒遵守尺寸或分格，先修正後再匯入；不要把不等大的格子直接當成等分圖切割。

## 後續待機與攻擊也沿用同一側面基準

- **待機：** 2 欄 × 2 排，四格；固定朝右、雙腳落地，只有小幅呼吸與衣物起伏。
- **攻擊：** 3 欄 × 3 排，九格；以朝右原地揮劍安排準備、蓄力開始、蓄力頂點、出劍、命中、揮擊收尾、收劍、回復與準備。全程維持側面、同一裝備與持用手，預留出手空間。
- 待機仍使用原本素材。攻擊已接入 `assets/sprite_sheet/player_attack.png`，預設 12 FPS；依實際圖像採 `1,2,3,5,4,6,7,8,9` 的順序，讓向前出劍接到向下收劍。
- 這份攻擊原圖有跨格情況，配套 `.animation.json` 使用獨立取圖範圍與統一畫布校正，並未改動 PNG。檢查它時保留現有分格設定，直接調整速度與偏移即可。

## 用檢查視窗驗收

在專案根目錄執行 `./inspect_sprites.ps1`，也可執行 `python sprite_sheet_inspector.py`。

1. 先用 **2 FPS、原地播放**：確認左右腳有交替跨步，而非身體晃動。
2. 暫停後用左右鍵逐格看，特別檢查 **第 3 → 4 格** 與 **第 6 → 1 格** 的銜接。
3. 開啟 **前格疊影、中心線與腳底線**：檢查角色的比例、水平位置與落地腳是否跳動。
4. 試 **6、10、15 FPS**，再開啟 **橫向移動預覽**，分別調整步頻與位移速度。
5. 可以調整播放順序、重複格號延長停留時間，以及逐格 X/Y 偏移。偏移只修正對齊，不能取代正確的姿勢。
6. 勾選 **連續動作**，檢查待機 → 接近 → 攻擊 → 返回的銜接。開啟目前的 `player_walk.png` 或 `player_attack.png` 時，尚未儲存的調整也會套入預覽。移速跟隨走路步頻，返回時維持朝右並倒序播放步伐。
7. 勾選 **並排比較：平滑／清晰**，比較遊戲尺寸下的輪廓與像素感；可搭配連續動作。這項比較不會改變遊戲的縮放方式。
8. 若原稿排列不齊，在 **切圖與校正 → 拖拉調整各格取圖範圍** 中選擇來源格，拖曳範圍或角落調整，按 **套用到預覽** 檢查。若需恢復等分取圖，「套用分格」會先確認是否清除原有取圖範圍、順序與偏移。
9. 按 **儲存動畫設定**，產生圖片旁的 `.animation.json`。目前遊戲會讀取 `player_walk.png` 與 `player_attack.png` 各自對應的設定，重新啟動後生效。

檢查工具不會重新繪製或覆寫 PNG。建議先將新圖存成不同檔名、檢查確認後，再切換遊戲使用的走路圖與配套設定。檢查工具的預設圖片應一起切換，以便調整同一組素材。
